# Примеры Gum

В этой папке лежат готовые файлы с примерами команд и конструкций языка. Большинство — старые `.sek`, новые — `.gum`. Работают оба расширения.

## Что здесь есть

- `01_print.sek` — вывод текста, чисел и склейка строк
- `02_msg.sek` — окно сообщения Windows
- `03_send.sek` — отправка текста и специальных клавиш
- `04_sleep.sek` — пауза в миллисекундах
- `05_variables.sek` — создание и изменение переменных
- `06_random.sek` — случайные числа
- `07_seed.sek` — фиксированный seed для повторяемого рандома
- `08_if_else.sek` — условия `if / elif / else`
- `09_loop.sek` — цикл `loop`
- `10_hotkey.sek` — хоткеи в стиле AHK
- `11_input.sek` — ввод строки из консоли
- `12_toggle.sek` — переключение boolean-переменной через toggle
- `13_click.sek` — левый клик мышью в текущей позиции курсора
- `14_use.sek` — подключение другого файла через `use`
- `15_type.sek` — проверка типа значения через `type(...)`
- `16_assert.sek` — остановка скрипта через `assert(...)`
- `17_group.sek` — группы команд через `group`
- `18_set.sek` — изменение переменной через `set`
- `19_save_load.sek` — сохранение и загрузка переменных
- `20_files.sek` — создание, чтение, изменение, копирование и удаление файлов через `os_*`
- `21_mousemove.sek` — перемещение курсора мыши
- `22_http_get.sek` — HTTP GET-запрос
- `23_http_post.sek` — HTTP POST-запрос
- `24_json.sek` — парсинг JSON: вложенные объекты, массивы, `nil`, `json_type`
- `25_telegram.gum` — Telegram-бот: `tg_token`, `tg_on`, `on_tg_message`, `on_tg_callback`

## Как использовать

Если хочешь запустить конкретный пример:

```bat
run.bat examples\06_random.sek
```

Если пример связан с окнами или вводом:

- `03_send.sek` требует, чтобы нужное окно уже было в фокусе
- `13_click.sek` требует, чтобы курсор уже был в нужном месте
- `02_msg.sek` и `10_hotkey.sek` показывают окна Windows
- `10_hotkey.sek` остаётся запущенным и ждёт нажатий
- `11_input.sek` ждёт ввод текста из консоли
- `21_mousemove.sek` двигает курсор по экрану — не запускай рядом с важными окнами

## Telegram-бот (25_telegram.gum)

Этот пример нельзя запустить «как есть» — сначала вставь токен бота вместо `<TOKEN>`.

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Открой `examples/25_telegram.gum` и замени `tg_token "<TOKEN>"` на свой токен.
3. Запусти:

```bat
run.bat examples\25_telegram.gum
```

4. Напиши боту `/start` — он ответит «Привет, я бот!», на любой другой текст — «Я не знаю такой команды...».

Что показывает пример:

- `tg_token "<TOKEN>"` — установка токена (проверяется через `getMe`; при невалидном токене скрипт остановится);
- `tg_on "/start" "Привет, я бот!"` — статичный ответ без написания обработчика;
- `group on_tg_message` — обработчик всех сообщений; `TG_TEXT` сравнивается с `tg_cmd_hash("/start")`;
- `tg_send`, `tg_reply`, `tg_typing`, `sleep`, `tg_callback_answer`, `tg_edit` — команды бота.

Подробная документация всех Telegram-команд — в корневом `README.md` (раздел «Telegram-боты»).

## Зачем нужен `07_seed.sek`

Обычный `random()` даёт новые значения.
Но иногда полезно получить одинаковый результат несколько раз подряд, например для тестов.
Для этого существует `seed(123)`.

## Зачем нужны хоткеи

Файл `10_hotkey.sek` нужен как быстрый пример автоматизации:

- нажал `x`
- выполнился код
- отправился текст или показалось сообщение

Это удобно для макросов и простых автоматизаций.

`09_loop.sek` можно использовать и как шаблон для бесконечного цикла:

```text
loop
click
sleep 10
end
```

## Пример короткого хоткея

Если нужен хоткей на одну команду, можно писать так:

```text
let enabled = true
f: toggle enabled
```

То есть при нажатии `f` переменная `enabled` будет переключаться между `true` и `false`.

## Пример группы `group`

Если хочется собрать несколько команд под одним именем:

```text
group setup
print "installing editor"
print "installing browser"
end

setup()
```

`group` сейчас без параметров: это именно группа команд, а не полноценная функция.

## Пример условий `and` / `or`

```text
let age = 25
if age >= 18 and age < 65
    print "взрослый, рабочий возраст"
end

if age < 10 or age > 80
    print "крайний возраст"
end
```
